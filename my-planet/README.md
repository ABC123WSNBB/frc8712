# 我的专属星球

3D 粒子星球、环绕星环、祝福文字与爱心动画，支持音乐、鼠标、触屏和摄像头手势。

## 使用

Windows 用户双击本目录的 `start.cmd`，浏览器会自动打开星球。需要已安装 Python 3，使用期间请保留启动窗口，关闭窗口即停止服务。启动器不依赖当前工作目录；默认使用 8765 端口，被占用时自动换用空闲端口。

也可以在此目录运行 `python serve.py`。不要直接双击项目中的 `index.html`：浏览器会阻止本地模块加载。基础星球效果无需联网。

点击右上角「定制我的星球」，填写标题、名字和祝福。保存后点击「绽放祝福」预览。每句最多 12 个字，共 1–8 句。设置保存在当前浏览器。

点击「导出专属页面」会下载含有你填写内容的 HTML，可重命名为 `index.html` 后上传静态托管。这个单文件版本运行时需要联网加载 Three.js。直接双击文件能否运行取决于浏览器对模块的限制，推荐通过本地服务或静态托管访问。

## 发布

若使用本项目发布，将 `index.html` 与 `vendor` 目录一起上传 Netlify 等静态托管平台，无需构建命令。想让所有访客看到你的默认祝福，可以把导出的 HTML 替换为上传目录中的 `index.html`；或编辑文件中 `starDefaults` 的 JSON 内容。浏览器内的保存操作只影响当前浏览器。

基础 3D 效果的 Three.js 依赖已随项目提供。手势功能需要 HTTPS 或 localhost、摄像头授权，并联网加载 MediaPipe 模型；未开启手势时不会请求摄像头。音乐由 Web Audio 实时生成，点击按钮后播放。
