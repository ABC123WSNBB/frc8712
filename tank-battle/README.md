# 沙暴能源站 · 坦克大战

一个原创视觉、零构建步骤的 HTML5 Canvas 坦克大战 MVP。游戏核心使用原生 JavaScript，Python 暂不参与浏览器游戏循环，后续可用于排行榜或 AI 服务。

## 运行

直接用现代浏览器打开 `index.html` 即可。若浏览器限制本地模块加载，在项目目录运行：

```powershell
python -m http.server 8000
```

然后访问 <http://localhost:8000>。部署到 GitHub Pages、Vercel 或 Netlify 不需要构建步骤。

## 操作

- `WASD` 或方向键：只控制车体移动，同时按两个方向键可斜走
- 鼠标位置：独立控制炮台和子弹方向；鼠标左键（按住可连续射击）或空格：射击
- `E`：使用已装备的炸弹；激光、冻结、炸弹是新增的坦克动荡风格机制
- `P`：暂停/继续
- `R`：重新开始

## MVP 设计

- 数据驱动的 24×16 十关沙漠能源站战役，敌人数量和强度逐关增加；第 3、6、9、10 关采用双倍难度倍率
- 砖墙可破坏、钢墙不可破坏、水域不可通行、沙丘减速
- Scout、Guard、Hunter 三类敌人
- 敌人使用可解释的有限状态机：巡逻、追击、射击；移动方向节流，遇到墙体才重新选路，炮台与车体方向分离
- AI 的移动速度不随关卡或技能增加。AI 会把玩家常用移动、瞄准和射击习惯匿名保存在本机 `localStorage`，跨局持续学习；并以可解释规则运用“知彼知己、避实击虚、声东击西、以逸待劳、围师必阙、因敌制胜”，配合预判瞄准和来弹闪避。第 3/6/9 关为小 Boss 关，第 10 关为最终 Boss 战
- AI 使用网格路线搜索、方向净空测量和卡死计时器；在角落或掩体边缘受阻时会选择空间最大的脱困方向
- 固定计分：击杀 100/200/300 分，破墙 10 分，无伤通关 500 分
- 每关至少掉落一次技能：敌我双方碰到技能包就自动装备。护盾抵消任意一次伤害；速射、加速、散射、激光和冻结有时限；维修即时恢复生命或装甲；炸弹用 `E` 释放范围伤害
- 用户提供的 WavePeak Elite 图像作为清晰可辨的轻微虚化背景品牌层，并叠加原创 `FRC` 标识
- 用户提供的 MP3 作为循环背景音乐；开始、暂停和音效按钮会同步控制播放状态
- 用户提供的新 MP3 作为进入游戏页面的默认开场音乐，页面加载时自动尝试播放；正式开局切换为战斗音乐，胜负结束后暂停，下次新游戏从头播放
- 用户提供的通关 MP3 在每一关完成时播放一次，不循环
- 用户提供的失败 MP3 在每次失败结算时播放一次，不循环
- 子弹穿过水域时速度降为正常速度的 42%；钢墙和地图边界会反弹，反弹后的子弹可以击毁发射者
- 玩家初始只有 1 条生命；每次通关增加 1 条附加生命，死亡时以碎片爆炸呈现并原地复活、获得 3 秒无敌；最终通关后清除附加生命
- 坦克采用 Canvas 原创绘制：履带底盘跟随移动方向，炮台和炮管独立跟随瞄准方向
- 最高分使用 `localStorage` 保存
- 所有坦克、地图和特效均由 Canvas 程序绘制，没有第三方游戏素材

## 结构

- `src/core.js`：地图、碰撞、计分和通用几何函数
- `src/entities.js`：坦克、子弹、粒子实体
- `src/main.js`：输入、游戏状态、AI、更新循环和渲染
- `assets/wavepeak-elite.jpg`：用户提供的背景图标素材
- `tests/core.test.mjs`：无需第三方依赖的 Node 逻辑测试

## 测试

在安装 Node.js 的环境运行：

```powershell
node --test tests/core.test.mjs
```
