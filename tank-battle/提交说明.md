# FRC 沙暴能源站 · 坦克大战

## 提交内容

本文件夹已经包含完整项目源码和可运行文件，不需要对方拥有 GitHub 账号，也不需要安装 Node.js。

- `index.html`：游戏入口文件
- `styles.css`：页面和 HUD 样式
- `src/`：游戏逻辑、坦克、子弹、AI、关卡和渲染代码
- `assets/`：背景图、开场音乐、战斗音乐、通关音效、失败音效
- `tests/`：自动化逻辑测试
- `启动游戏.bat`：Windows 双击启动文件

## 最简单运行方式

1. 双击 `启动游戏.bat`。
2. 浏览器会打开 `http://127.0.0.1:8000/`。
3. 在开始界面点击“开始作战”即可。

如果双击后没有自动打开浏览器：

1. 在本文件夹空白处右键，选择“在终端中打开”。
2. 输入 `python -m http.server 8000` 并回车。
3. 浏览器打开 `http://127.0.0.1:8000/`。

## 游戏操作

- `WASD` / 方向键：移动坦克，可斜向移动
- 鼠标位置：控制炮台方向
- 鼠标左键或空格：射击
- `P`：暂停/继续
- `E`：使用炸弹
- `R`：重新开始
