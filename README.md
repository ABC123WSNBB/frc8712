# 轨迹 · 三维计划球

本地单用户计划应用：球状计划网络、日/月计划管理、本地保存、JSON 备份及摄像头手势。

作为通用模块接入时，请查看 [MODULE.md](MODULE.md)。模块包含星云尘埃、循环彗星和节点交互，宿主传入计划并接收选择事件。

## 启动

在此目录运行 `powershell -ExecutionPolicy Bypass -File .\start.ps1`，打开 http://127.0.0.1:5173 。已安装依赖，无需联网加载手势模型。不要直接双击 HTML。

标准 Node/npm 环境也可以使用 `npm ci`、`npm run dev`、`npm run build`、`npm test`。手势模型和 WASM 已放在 `public/mediapipe`；模型来自 Google MediaPipe hand_landmarker float16 v1，WASM 来自锁定的 `@mediapipe/tasks-vision` 包。更新该包时须同步其 wasm 文件。

## 使用

- 新建日/月计划。日计划可归属同月的月计划；有子计划的月计划自动计算完成进度。
- 左侧索引支持键盘 Tab/Enter 操作；方向键旋转，+/− 缩放。编辑时暂停手势。
- 摄像头由按钮显式开启；碗状手转腕旋转，五指伸直放大，握拳缩小；食指指向后捏合并释放打开节点。
- 手势需稳定约 300ms。转腕尽量保持手掌可见，避免侧到完全遮挡手指。灵敏度可调。当前为几何启发式识别，碗状手仍需真人摄像头调校。
- 关闭摄像头或切走页面会释放摄像头。模型本地运行，不上传画面。
- 数据绑定当前浏览器及地址（协议、主机、端口）。固定使用同一地址，定期导出 JSON；清理浏览器数据会删除计划。
- 导入会在校验、确认后替换数据；本地数据损坏时停止写入，可导出原始备份后导入恢复。

## 验证

`npm test` 覆盖导入校验、月进度、删除关系和手势状态。`npm run build` 验证发布构建。真实手型和摄像头延迟需要用户在目标设备验证，不由合成测试证明。
